# Weft UI

A cross-platform UI library.

## Web demo

```sh
pnpm install
pnpm build:wasm                 # compiler as WASM for the Vite plugin
pnpm --filter todo-web dev      # examples/todo-web
pnpm test                       # end-to-end tests (happy-dom)
```
